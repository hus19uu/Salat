# الصلاة: وقت قليل بأثر جليل.

موقع ويب تفاعلي باللغة العربية، مناسب للهاتف والحاسوب.

## ما محتويات هذه الحزمة؟
- `index.html` — صفحة الموقع كاملة؛ يجب رفعها بهذا الاسم تحديدًا إلى جذر المستودع.
- `.nojekyll` — ملف فارغ يجعل GitHub Pages يقدم الصفحة كما هي، دون تحويل بواسطة Jekyll.

## النشر المجاني على GitHub Pages
1. افتح https://github.com/new وسجّل الدخول.
2. اكتب اسم المستودع `salat-waqt-qalil`، واختر **Public**، ثم **Create repository**.
3. افتح المستودع، ثم اضغط **Add file** > **Upload files** (أو رابط **uploading an existing file** إذا كان المستودع فارغًا).
4. ارفع ملف `index.html` **من داخل هذه الحزمة** إلى جذر المستودع؛ يمكنك أيضًا رفع `.nojekyll` إن ظهر في مدير الملفات (وهو اختياري هنا).
5. اضغط **Commit changes** لتأكيد الرفع.
6. ادخل إلى **Settings** > **Pages**.
7. تحت **Build and deployment** اجعل **Source** = **Deploy from a branch**، والفرع **main**، والمجلد **/(root)**، ثم اضغط **Save**.
8. بعد نجاح النشر، افتح **Settings > Pages > Visit site** للحصول على الرابط الحقيقي.

شكل الرابط المتوقع بعد نجاح النشر:
`https://USERNAME.github.io/salat-waqt-qalil/`
استبدل `USERNAME` باسم المستخدم الفعلي. **لا تعد الرابط منشورًا قبل ظهور Visit site وفتح الصفحة بنجاح**.

قد يستغرق ظهور الموقع أو تحديثه نحو 10 دقائق بحسب وثائق GitHub.

## تعديل الموقع لاحقًا
استبدل `index.html` في المستودع بالإصدار المحدّث من الملف، ثم اضغط **Commit changes**، وسيُعاد النشر تلقائيًا.

## تنبيهات تقنية ومعلوماتية
- تعتمد المواقيت المحسوبة على اتصال الإنترنت وخدمة AlAdhan API (طريقة الحساب رقم 23)، وقد تختلف عن التقويم الرسمي المحلي. راجع جدول وزارة الأوقاف عند الحاجة.
- حفظ علامات الصلاة والخطة الشخصية يتم محليًا في متصفح المستخدم عند السماح بذلك، وليس مزامنة بين الأجهزة.
- الموقع لا يصدر إشعار أذان مستقلًا عندما يكون المتصفح مغلقًا.
- زر «مشاركة» يُستخدم بعد النشر للحصول على رابط عام؛ أما فتح HTML كملف محلي فلا ينتج رابطًا عامًا.
